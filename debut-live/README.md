# AI FES 2026 デビューライブ 受賞選定ツール

AFS役員審査ツールと同じ「1ファイル完結・オフライン動作」の設計を踏襲した、**デビューライブ用の内部スタッフ向け受賞選定ツール**です。役員による選出は行わず、**ルーブリック採点＋いいね加点＋HTML加点の自動集計で上位6件を毎月選出**します。

配布物は `dist/AIFES2026_デビューライブ_受賞選定ツール.html` の1ファイルです。ダブルクリックしてブラウザ（Edge / Chrome）で開くだけで動作し、ネット接続やサーバーは不要です。

## AFS役員審査ツールとの違い

| | AFS役員審査 | デビューライブ |
|---|---|---|
| 選ぶ人 | 役員が3件ずつ選出（合議なし） | いない。スコア自動集計で上位6件を選出 |
| ツール数 | 役員6名分＝6ファイル | 1本（内部スタッフ用） |
| いいね | 参考表示のみ、スコア対象外 | **スコアの3本柱の1つ**（もらった数そのまま加点、上限+25） |
| 開催サイクル | 通期で1回 | **月次**。毎月上位6名 |
| 連続受賞 | 運営が個別に「連覇除外」を設定 | **仕組みとして必須**：一度受賞したら以降の月は対象外 |

## 最終スコア

```
最終スコア = ルーブリック（4指標・100点満点）
           + いいね加点（もらったいいね数そのまま、上限 +25）
           + HTML加点（作品ファイルHTML→+5／手順書ファイルHTML→+5、上限 +10）
```

- ルーブリックは `in/05_デビューライブ.md` を参照（核心思想「ハードルを乗り越えた初体験を語れる人」、4指標×25%×満点10）
- あげたいいね数（上限15）はデータ収集側で処理済みのため、このツールでは考慮しません
- 同点時の優先順位：① ルーブリック生点が高い方 → ② いいね数が多い方 → ③ スタッフが手動で順位を入れ替え

## 使い方

1. `dist/AIFES2026_デビューライブ_受賞選定ツール.html` をブラウザで開く
2. 右上「対象月」に `2026年7月` のように入力
3. 「採点マスターExcelを読み込む」で、AIがルーブリック採点済みのエントリー一覧（列構成は下記）を読み込む
   - 上位6件が自動で受賞候補になる（金色のカード）
4. 前月までに書き出した「受賞一覧Excel」があれば「過去の受賞者Excelを追加」にドロップする
   - その受賞者は今月の対象から自動的に除外され、行が淡色化・順位選択不可になる
   - 複数月分をまとめて追加できる
5. 受賞候補カードのプルダウンで、必要なら順位を手動で入れ替える（誤検知・欠損対応）。一覧表の各行の「順位」プルダウンからも同様に変更できる
6. 各受賞候補カードに受賞理由・講評コメントを記入する
7. 「入力チェック」で受賞理由の記入漏れ等を確認
8. 「Excelを書き出して提出」→ `受賞一覧`シート（次月の除外リストとしてそのまま再利用可）と `全エントリー`シート（参考・監査用）が入ったExcelが出力される

入力内容（対象月ごとの受賞順位・受賞理由・講評コメント・除外リスト）はブラウザのlocalStorageに自動保存されます。閉じて開き直しても残ります。「入力を全消去」でその対象月分だけ消せます。

## 採点マスターExcelの列構成

`EntryCode` と `観点①スコア`〜`観点④スコア` を含むシートを自動検出して読み込みます。想定する列名（別名も一部許容）：

| 列名 | 内容 |
|---|---|
| `EntryCode` | エントリーコード（必須） |
| `GlobalEntryId` | 全体ID |
| `対象月` | 例）2026年7月（あれば自動で「対象月」欄に反映） |
| `応募者・部署` | `氏名/部署`。区切りは半角 `/`（全角`／`にも対応） |
| `作品リンク` | 未入力の場合は「資料欠損」扱いで受賞対象外になる |
| `ProcedureFileUrl` | 手順書リンク |
| `観点①スコア`〜`観点④スコア` | 各0〜10点（デビューライブのルーブリック4指標） |
| `作品ファイル形式` / `手順書ファイル形式` | `HTML` の場合のみそれぞれ+5点 |
| `いいね（もらう）` | もらったいいね数（生の値。上限+25はツール側で適用） |
| `AI講評` | 参考表示（任意） |

`RubricTotal`（ルーブリック合計）列がなければ、4指標から `Σ(獲得点÷10×25)` で自動計算します。

## ビルド方法（開発者向け）

`dist/` の配布ファイルは `build/template.html` に SheetJS（`build/package/dist/xlsx.mini.min.js`）を埋め込んで生成しています。ツールのロジックを変更する場合は `build/template.html` を編集し、以下を実行してください。

```
cd build
python3 build.py
```

## テスト・ダミーデータ

`dummy/` に検証用の一式があります。

```
cd dummy
python3 make_dummy.py     # ダミーの採点マスター(15件)と前月受賞一覧(2名)を生成
NODE_PATH=/opt/node22/lib/node_modules node test_tool.js   # headless Chromiumでの自動回帰テスト
```

`test_tool.js` は以下を検証します：採点マスターの読み込み、最終スコアの自動算出とランキング、資料欠損の除外、過去受賞者Excelによる除外、順位の手動オーバーライド（重複なく入れ替わること）、入力チェック、Excel書き出し、JSエラーが出ないこと。
