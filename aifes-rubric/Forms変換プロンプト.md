# 審査員向け評価フォーム エクスポート → 集計ツール入力データ 変換プロンプト

Forms のエクスポート（xlsx / CSV）をそのまま集計ツールに流せる形へ整えるためのプロンプト。
以下をコピーして生成AIに貼り、指定の2つを一緒に渡す。

---

## 渡すもの（2つとも必須）

1. **Forms のエクスポート**（xlsx をそのまま添付、または CSV として貼り付け）
2. **登壇順 → 部署名の対応表**（下の形式で本文に書く）

```
登壇順の対応表
1番目：○○事業本部
2番目：△△部
3番目：□□統括部
4番目：××本部
```

**この対応表がないと変換できません。** エクスポートの列名は `業務変革` `業務変革2` `業務変革3` `業務変革4`
という登壇順のサフィックスだけで、部署名がどこにも入っていないためです。

---

## プロンプト本文（ここから下をコピー）

````
あなたはアンケート集計データのクレンジング担当です。
添付した Microsoft Forms のエクスポートを、集計ツールに投入できる形へ変換してください。
値の判断や補完は一切せず、機械的な変換だけを行ってください。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 入力データの構造（この形になっているはずです）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

先頭6列は固定です。
  ID / 開始時刻 / 完了時刻 / メール / 名前 / 最終変更時刻

7列目以降は、8列を1セットとして4回くり返します。1セット＝1部署（登壇順）です。
セット内の並びは必ずこの順です。

  1. 業務変革
  2. 組織への広がり・定着
  3. 人・チームの変化
  4. 成果と創出時間の活用
  5. 再現性・資産化
  6. 他部門・全社への波及と未来
  7. この部署を一言でいうと？
  8. 気になった点、別室で確認したいこと

2セット目以降は列名の末尾に 2 / 3 / 4 が付きます（例：`業務変革2` は登壇2番目の業務変革）。
サフィックスなし＝登壇1番目です。

1行が審査員1名の回答で、その中に4部署分の採点が横に並んでいます。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ やること
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【1】評価値を数値にする
　セルの値は「2 = 限定的」のような文字列です。先頭の数字だけを取り出してください。

　　1 = 確認できない      → 1
　　2 = 限定的            → 2
　　3 = 取り組みが見える  → 3
　　4 = 部として定着      → 4
　　5 = 他部門でも使える  → 5

　この5種類以外の値が出てきたら、勝手に解釈せず「不明」として残し、最後に報告してください。

【2】列名のサフィックスを登壇順に読み替え、部署名に置き換える
　サフィックスなし→1番目、2→2番目、3→3番目、4→4番目。
　本文で渡した対応表を使って、登壇順を部署名に変換してください。

【3】横持ちを縦持ちに変える
　1行＝審査員1名×4部署 という形を、1行＝審査員1名×1部署 に展開してください。
　審査員が12名なら 12×4＝48行になります。

【4】未入力を判定する
　空欄は 0 や平均で埋めないでください。空欄のまま「未入力」として残します。
　6観点のうち1つでも未入力がある部署は、その行に `未入力あり` の印をつけてください。

【5】全部署を採点したかを判定する
　4部署すべてで6観点すべてが埋まっている審査員だけを `有効=はい` とします。
　1部署でも欠けている審査員は、4行すべてを `有効=いいえ` にしてください。
　（部署ごとに採点者数が変わると平均が比較できなくなるためです）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 出力（3つとも出してください）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

《出力1》採点データ（CSV。ヘッダー行を含める）

審査員,メール,登壇順,部署名,業務変革,組織への広がり・定着,人・チームの変化,成果と創出時間の活用,再現性・資産化,他部門・全社への波及と未来,合計,未入力あり,有効

　・合計＝6観点の素点合計（30点満点）。未入力がある場合は空欄にする
　・未入力あり／有効＝ はい / いいえ

《出力2》自由記述（CSV。ヘッダー行を含める）

審査員,登壇順,部署名,一言,気になった点

《出力3》検算レポート（次の項目を必ず書く）

　・審査員の人数：N名
　・出力した行数：N×4＝M行（一致しているか）
　・有効な審査員：N名／無効：N名（無効の場合はその氏名と欠けている箇所）
　・「1〜5」以外の値が出たセル：あればその場所と値、なければ「なし」
　・部署ごとの採点者数：4部署とも同じ人数か
　・各部署の素点合計の最小値・最大値

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 守ること
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

・元データにない値を作らないでください。空欄は空欄のまま出します。
・合計や順位の解釈、優劣のコメントは書かないでください。変換だけが仕事です。
・氏名・メールは元データのまま転記してください。表記ゆれを直さないでください。
・出力1・2・3以外は書かないでください。
````

---

## 使ったあとの確認

生成AIの転記なので、次の3点だけ目で確かめてください。ここが合っていれば中身も概ね合っています。

1. **行数**が「審査員の人数 × 4」になっているか
2. **検算レポートの「1〜5以外の値」が「なし」**になっているか
3. 任意の1行を選び、**元のエクスポートの該当セルと6つの数字を突き合わせる**

このうち1つでも合わなければ、変換をやり直してください。
件数が増えて毎回の確認が重くなる場合は、同じ変換を Python スクリプトで固定できます（毎回同じ結果になり、検算も自動化できます）。

---

## 補足：この変換で吸収している「Forms 固有のクセ」

堤さんの指摘②「Forms固有の列名を、HTML側で吸収して正しく集計できるのか」に対応する部分です。

| Forms のクセ | このプロンプトでの扱い |
|---|---|
| 選択肢が `2 = 限定的` という文字列で出る | 先頭の数字だけを取り出して数値化 |
| 同じ設問が4回くり返され、2回目以降に `2` `3` `4` が付く | サフィックスを登壇順として読み替え |
| 部署名がどこにも入っていない | 対応表を人手で渡して置き換え（自動化不可） |
| 1行に4部署分が横に並ぶ | 縦持ちに展開して1行1部署にする |
| 未入力が空欄で出る | 0埋めせず「未入力」として残し、有効／無効を判定 |
