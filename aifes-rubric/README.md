# AIFES 2026 グランドフィナーレ AI予備審査ルーブリック

審査員12名それぞれに個別に審査を依頼することなく、AIで予備審査を一次実施するための共通ルーブリック一式。
12名のコメントを6観点に集約しているため、1回の採点で全員の観点が反映される。

## 成果物

| ファイル | 内容 |
|---|---|
| `AIFES2026_グランドフィナーレ_AI予備審査ルーブリック.xlsx` | 全7シート。ルーブリック本体・審査員対応表・採点シート（自動集計）・判定ルール・AI審査プロンプト・元データ |
| `AI予備審査プロンプト.md` | そのままAIに貼って使えるプロンプト全文 |
| `審査員向け説明資料.html` | 審査員12名への説明・合意形成用 |
| `審査員コメント一覧_原本.xlsx` | 元データ（未加工） |

## 設計

- **集約方針**：「グランドフィナーレコメント」を主（◎）、各ステージ向け「審査コメント」を従（○）として6観点に集約。
- **配点**：`言及重み = ◎の数 × 1.0 + ○の数 × 0.5` を100点に正規化（最大剰余法）。決め打ちしていない。役職による重み付けも行っていない。
- **前提フラグ F1〜F4**：「それ単体では評価に値しない」という趣旨のコメント（生産性向上は前提、個人依存 等）は、加点ではなく該当観点のレベル上限として実装。

| 観点 | 配点 |
|---|---|
| C1 業務そのものの再設計と「やめる」判断 | 18 |
| C2 組織への浸透と参加の広がり | 20 |
| C3 仕組み化と会社のプロセス資産化 | 11 |
| C4 波及範囲と経営視座 | 22 |
| C5 創出した価値と、その再投資先 | 9 |
| C6 語りの当事者性と熱量 | 20 |

## 再生成

観点・配点・レベル記述の定義元は `rubric_data.py` の1ファイルのみ。ここを編集して再実行すれば、3つの成果物すべてに同時に反映される。

```bash
pip install openpyxl
python3 build_prompt.py   # → AI予備審査プロンプト.md
python3 build_xlsx.py     # → .xlsx（プロンプトシートを含む）
python3 build_html.py     # → 審査員向け説明資料.html
python3 /root/.claude/skills/xlsx/scripts/recalc.py <xlsx> 300   # 数式の再計算・検証
```

`build_xlsx.py` は `build_prompt.py` を import するため、`build_prompt.py` を先に用意しておくこと。
