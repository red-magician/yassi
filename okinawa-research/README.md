# 沖縄横展開プロジェクト（AI FES 2026 測定班）

沖縄のAI FES参加率が高い要因を調べ、**他拠点で再現できる打ち手**として横展開するための一式。

## 目的（壁打ちで確定）

沖縄の成功要因から「他拠点でも再現できる打ち手」を抽出して提言する（＝現状把握で終わらせない）。
参加率は **エントリー率（入口）** と **アクティブ率（継続）** の両輪で見る。

## 成果物

| ファイル | 中身 | 使うタイミング |
|---|---|---|
| `AIFES2026_沖縄横展開_ヒアリング設計書.html` | A:大坪さん（手法）／B:渋って→参加したメンバー（ベネフィット）／C:未参加者（反論）の質問票。各質問に狙いと成果物タグつき | ヒアリング前に印刷して持参 |
| `AIFES2026_沖縄横展開_依頼事項リスト_テンプレ.html` | 他拠点アンバサダー向け「行動の依頼＋沖縄の実例」テンプレ（v0） | ヒアリングA後に実例を記入して確定 |
| `AIFES2026_勧誘チラシ_雛形.html` | 未参加メンバー向け勧誘チラシ「反論→崩す声→ベネフィット」構成の雛形 | ヒアリングB/C後に声を差し込んで完成 |
| `shukei/` | 拠点別参加率の集計スクリプト | 実マスターExcelが用意でき次第 |

担当（ヒアリング実施）：城間さん。

## 進め方

1. **ヒアリングA（大坪さん）** … 手法を採る＋B/Cの対象者を紹介してもらう
2. **ヒアリングB（渋って→参加した人）→ C（未参加者）** … B1/C1の反論が揃うとチラシの骨子が固まる
3. 記入 … A→依頼事項リスト、B/C→勧誘チラシ
4. 並行して **拠点別参加率** を集計（下記）し、報告書の"つかみ"に

## 拠点別参加率の集計（shukei/）

実マスターExcelを読み込み、拠点ごとに **エントリー率**（参加者÷在籍人数）と
**アクティブ率**（複数投稿者÷参加者）を出し、沖縄の突出度を可視化する。

```
cd shukei

# 実データが無いうちは、拠点情報つきダミーで動作確認
python3 make_dummy_sanka.py
python3 sanka_ritsu.py dummy_master_sanka.xlsx

# 実データが来たら（社外秘なので shukei/real/ 等に置く。.gitignore対象）
python3 sanka_ritsu.py real/実マスター.xlsx --highlight 沖縄
```

- 依存: `openpyxl`（`pip install openpyxl`）
- 読み込む列は表記ゆれを自動許容（拠点＝拠点/事業所/勤務地/Office…、人＝SubmitterEntraId/Email/表示名）
- **実データに「拠点」を識別できる列が必要**。無い場合はスクリプトがエラーで知らせる
- 在籍人数シート（社員名簿）が無い場合は、エントリー率は「-」とし参加者数・アクティブ率のみ出す
